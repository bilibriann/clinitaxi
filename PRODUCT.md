# Product

## Platform

web

## Stack

NestJS 11 (API) + React 19 + Vite 6 + Tailwind CSS v4. Dev: `npm run dev` (concurrently starts NestJS watch + Vite HMR). Build: `npm run build`.

## Users

**Taxistas independientes** — conductores individuales que necesitan certificar, instalar o reparar su taxímetro para cumplir la normativa del Ministerio de Transportes. Visitan el sitio para confirmar que CLINITAXI es el proveedor autorizado y encontrar dónde contactarlos.

**Dueños de flota / empresas de taxi** — administran múltiples vehículos; buscan un proveedor confiable con cobertura nacional y capacidad de atención masiva. Ambas audiencias tienen igual peso.

## Product Purpose

CLINITAXI vende, instala y certifica taxímetros en Chile. El sitio es una página informativa cuyo objetivo es convertir visitantes en contactos calificados (llamada o formulario). El éxito es que el taxista o gestor de flota termine sabiendo que CLINITAXI es el proveedor correcto y tome acción de contacto.

## Positioning

CLINITAXI es **la única empresa autorizada** (o una de muy pocas) por el Ministerio de Transportes de Chile para certificar taxímetros no adulterables. Ningún competidor puede copiar esa credencial oficial. Refuerza con 25+ años de trayectoria.

## Operating Context

- Taxistas consultan el sitio desde móvil, frecuentemente mientras están en ruta o en paradas.
- Gestores de flota pueden visitar desde escritorio en un contexto de evaluación de proveedor.
- El trámite de certificación es una obligación legal; el visitante llega con urgencia o con una fecha límite de revisión técnica.
- La atención presencial y telefónica son el canal de cierre; el sitio web es el primer punto de confianza.

## Product Principles

1. **Credibilidad primero** — la certificación oficial es el activo más poderoso; debe ser inmediatamente visible y verificable.
2. **Claridad operacional** — el taxista llega con una necesidad concreta; el sitio le indica en segundos qué hacer y cómo contactar.
3. **Confianza ganada por trayectoria** — 25 años y presencia en 8 regiones son señales de permanencia; el diseño debe proyectar solidez, no modernidad vacía.
4. **Acción sobre información** — cada sección empuja hacia el contacto; el contenido informativo es instrumental, no decorativo.
5. **Mobile-first real** — el taxista independiente llega desde el celular; el sitio debe funcionar perfectamente en ese contexto.
